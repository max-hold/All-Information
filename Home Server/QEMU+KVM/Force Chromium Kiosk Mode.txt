## Option 1 (Best): systemd service watchdog

- Good call — a watchdog is what turns a “mostly stable” kiosk into something production-grade.
- The cleanest way is to let systemd supervise Firefox instead of relying on scripts alone. That way, if Firefox crashes, freezes, or exits → it restarts automatically.

# Create a systemd service
```
sudo nano /etc/systemd/system/kiosk.service
```
- Paste:
```
[Unit]
Description=Firefox Kiosk
After=network.target

[Service]
User=kiosk
Environment=DISPLAY=:0
Environment=XAUTHORITY=/home/kiosk/.Xauthority

ExecStart=/usr/bin/firefox --kiosk --private-window --no-remote --new-instance https://your-dashboard-url.com
Restart=always
RestartSec=3

# Watchdog behavior
StartLimitIntervalSec=0

[Install]
WantedBy=graphical.target
```

# Enable the service
```
sudo systemctl daemon-reexec
sudo systemctl daemon-reload
sudo systemctl enable kiosk.service
```

# Start it
```
sudo systemctl start kiosk.service
```
- What this gives you
    Firefox auto-restarts on crash
    Restarts if user somehow closes it
    Restarts if it exits for any reason
    3-second delay prevents rapid crash loops


## Option 2: Detect freezes (advanced watchdog)

- Systemd only restarts when the process exits, not when it hangs.
- To detect freezes, add a watchdog script:
# Create watchdog script
```
nano /home/kiosk/watchdog.sh
```

```
#!/bin/bash

URL="http://localhost"   # or your kiosk URL
TIMEOUT=10

while true; do
    if ! curl -s --max-time $TIMEOUT $URL > /dev/null; then
        echo "Firefox unresponsive, restarting..."
        pkill firefox
    fi
    sleep 15
done
```

- Make executable:
```
chmod +x /home/kiosk/watchdog.sh
```

- Add it to systemd (recommended)
- Edit your service:
```
sudo nano /etc/systemd/system/kiosk.service
```

- Add:
```
ExecStartPost=/home/kiosk/watchdog.sh
```

# Even better: Separate watchdog service
```
sudo nano /etc/systemd/system/kiosk-watchdog.service
```

```
[Unit]
Description=Kiosk Watchdog
After=kiosk.service

[Service]
User=kiosk
ExecStart=/home/kiosk/watchdog.sh
Restart=always

[Install]
WantedBy=graphical.target
```

- Enable:
```
sudo systemctl enable kiosk-watchdog.service
```

- If X server dies, Firefox won’t restart.
```
while true; do
    startx
    sleep 2
done
```

## Build a read-only OS (immutable kiosk)

- Now you’re stepping into serious kiosk engineering — a read-only (immutable) system is how airports, ATMs, and digital signage stay tamper-proof.

After setup:
    System boots straight into kiosk
    Filesystem is read-only
    Any changes are wiped on reboot
    Users cannot persist changes (even with access)



We’ll combine:
    Read-only root filesystem (/)
    Writable temp areas (/tmp, /var, /home)
    Overlay filesystem (RAM-backed)
    Your existing Firefox kiosk + watchdog

# Install required tools
```
sudo apt install overlayroot
```

# Enable read-only root (overlay mode)
- Edit config:
```
sudo nano /etc/overlayroot.conf
```

- Set:
```
overlayroot="tmpfs"
```

- This means:
    Base system = read-only
    All writes go to RAM (tmpfs)
    Reboot = everything resets


# Preserve only what you NEED (optional)

If you want persistence (logs, configs), use:
```
overlayroot="tmpfs:swap=1,recurse=0"
```

# Disable password login:
```
sudo passwd -l kiosk
```

# Disable shell access:
```
sudo usermod -s /usr/sbin/nologin kiosk
```

# Disable package/system changes
```
sudo systemctl disable apt-daily.service
sudo systemctl disable apt-daily-upgrade.service
```

- Optional: remove package managers entirely
```
sudo apt remove apt
```

# Lock critical directories (extra hardening)
- Even though root is read-only, reinforce:
```
sudo chattr +i /etc/passwd
sudo chattr +i /etc/shadow
sudo chattr +i /etc/group
```

# Make /home and /tmp volatile (RAM only)
- Edit:
```
sudo nano /etc/fstab
```

- Add:
```
tmpfs /tmp tmpfs defaults,noatime,nosuid,size=512M 0 0
tmpfs /home tmpfs defaults,noatime,size=512M 0 0
```

# Ensure kiosk auto-start still works
```
sudo mkdir -p /opt/kiosk
sudo cp /home/kiosk/kiosk.sh /opt/kiosk/
```

- Update your systemd service:
```
ExecStart=/opt/kiosk/kiosk.sh
```

# Keep watchdog + systemd
- Your previous setup still works — systemd lives in read-only base.

# Test before enabling (IMPORTANT)
```
sudo overlayroot-chroot
```

# Reboot into immutable mode
```
sudo reboot
```

- After reboot:
    Try editing a file → it will revert on next boot.


- What you now have
    Fully read-only OS
    Firefox kiosk auto-launch
    Auto-restart watchdog
    No persistent tampering
    Clean state every reboot

- Trade-offs (be aware)
    Logs disappear unless redirected
    Updates require disabling overlay temporarily
    Any config changes are lost after reboot
