Core Installation
The basic command to install the browser is:
bash
apk add chromium
Recommended: Docker/CI Practice
If you are building a Docker image, it is best practice to include the --no-cache flag to keep the image size small and ensure you are getting the latest package index.

Common Extensions & Dependencies
Depending on your use case, you may need additional packages:
For Selenium/Automation: Most automation tools require the corresponding driver.
bash
apk add chromium-chromedriver
For Rendering/Fonts: Alpine is a minimal distribution and lacks standard fonts. Without these, Chromium may render text as blocks or crash.
bash
apk add ttf-freefont font-noto-emoji
For Headless Mode (Puppeteer/Playwright): You often need to set environment variables so the tool knows where the binary is located.
bash
export CHROME_BIN=/usr/bin/chromium-browser

Important Notes
Running as Root: Chromium includes a "sandbox" for security that typically prevents it from running as the root user. In Docker, you must either create a non-privileged user or run Chromium with the --no-sandbox flag.
Architecture Support: Chromium is available in the Alpine Community Repository for most major architectures (x86_64, aarch64, etc.).
Resource Usage: Chromium is a heavy application. Ensure your environment (especially if it is a container) has enough memory allocated to prevent "Out of Memory" (OOM) errors during startup.
