Windows Sandbox Automation
1
2
Automating Windows Sandbox can greatly streamline testing, development, and secure execution of applications. With recent updates in Windows 11 (24H2), Microsoft introduced a Windows Sandbox CLI for scripting and automation, alongside community tools like CustomSandbox for advanced configuration.

Using Windows Sandbox CLI

1. Start a Sandbox

wsb start
Copy
To start with custom settings:

wsb start --config "<Configuration><Networking>Disabled</Networking></Configuration>"
Copy
2. List Running Sandboxes

wsb list
Copy
3. Execute Commands Inside Sandbox

wsb exec --id <sandbox-id> -c "app.exe" -r System
Copy
4. Share Folders

wsb share --id <sandbox-id> -f C:\host\folder -s C:\sandbox\folder --allow-write
Copy
5. Stop a Sandbox

wsb stop --id <sandbox-id>
Copy
Using CustomSandbox PowerShell Utility

CustomSandbox is a community PowerShell script that pre-configures and automates software installation in Windows Sandbox.

Steps:

Download & Extract

Invoke-WebRequest 'https://github.com/oOblik/CustomSandbox/releases/latest/download/CustomSandbox.zip' -OutFile .\CustomSandbox.zip
Expand-Archive .\CustomSandbox.zip .\
cd CustomSandbox
Copy
Run the Script

\CustomSandbox.ps1
Copy
Configure Tasks Enable/disable networking, vGPU, clipboard. Pre-install apps like Chrome, VS Code, Notepad++, Git. Cache installers for offline use.

Verification: After automation setup, run wsb list to confirm sandbox sessions and configurations. Test shared folders and installed software inside the sandbox.

Tips:

Use CLI for lightweight automation in scripts or CI/CD pipelines.

Use CustomSandbox for complex setups with multiple pre-installed tools.

Always enable only required permissions (e.g., networking) for security.
